================================================================================
眠音盒小程序 · 弹窗推荐方案（不含「接着播」）
================================================================================
版本：v1.0
范围：运营/商品/活动类弹窗的展示策略与实现路径；不涉及全局续播、后台音频。

参考产品：酷狗、网易云等「时不时弹一下」的能力，本质是：
  触发时机 + 频控 + 远程配置 + 统一弹窗 UI，与播放器无关。

--------------------------------------------------------------------------------
一、目标
--------------------------------------------------------------------------------

1. 在合适场景向用户展示推荐（眠家好物、活动、歌单、功能引导等）。
2. 可配置「多久弹一次、每天几次、点关闭后多久再弹」。
3. 全站关闭状态一致：任意页面选「今天不再显示」，其他页面当天也不再弹同类推荐。
4. 不打扰核心流程：生成中、支付中、录音中、分享画布导出中等场景禁止弹窗。

非目标（本方案不做）：
  - 切页/返回后续播
  - 与 InnerAudioContext / global-audio 联动

--------------------------------------------------------------------------------
二、现状（2025 实施前）
--------------------------------------------------------------------------------

已有「弱推荐」形态，非居中弹窗：

  页面              形态           关闭存储 key（各自独立）
  ----------------  -------------  ------------------------------------------
  首页 create       横幅条         mb_home_mianjia_entry_dismissed_date
  完成页 complete   横幅条         mb_complete_mianjia_tip_dismissed_date
  播放页 player     底部提示条     mb_player_mianjia_tip_dismissed_date

问题：
  - 三处 key 互不影响，用户以为「全站今天不显示」，实际只关当前页。
  - 无统一频控（次数、间隔、优先级）。
  - 无远程开关，发版才能改文案/上下线。
  - 无「强弹窗」（居中 Modal / 底部 Sheet）能力。

本方案建议：保留横幅作为轻量入口，弹窗走统一调度器；关闭与频控全站共用。

三、总体架构
--------------------------------------------------------------------------------

                    │  远程配置 / 接口     │

                    │  · 是否可弹         │

                    │  · 优先级仲裁       │
                    └──────────┬──────────┘
           ┌───────────────────┼───────────────────┐
           ▼                   ▼                   ▼
    ┌─────────────┐     ┌─────────────┐     ┌─────────────┐
    │ 首页 onShow │     │ 完成 onShow │     │ 播放 onShow │

                    └─────────────────────┘

页面只负责两件事：
  1. onShow 时调用 scheduler.tryShow({ scene: 'home' })
  2. 页面上挂 <promo-popup id="promo-popup" />，由 scheduler 或页面 setData 控制显隐

--------------------------------------------------------------------------------
四、弹窗类型（UI）
--------------------------------------------------------------------------------

建议支持三种模板，由配置字段 type 决定：

  类型          说明                          适用
  ------------  ----------------------------  ------------------
  center_image  居中图 + 关闭角标 + 主按钮    大促、眠家专题、节日活动
  bottom_card   底部卡片（类似现有眠家条）    轻引导，不打断浏览
  toast_link    仅 Toast + 可点文字链        极低打扰，试验用

交互统一：
  - 主按钮：跳转（小程序 path / 外链 web-view / 眠家分包页）
  - 关闭：右上角 X 或「关闭」
  - 关闭二次确认（与现有一致）：
      · 仅本次关闭 → 本次会话内不再弹该 promoId
      · 今天不再显示 → 写入全站 dismiss（见第五节）

注意：微信规范上避免诱导分享、虚假关闭；活动需可关闭，不要无限弹。

--------------------------------------------------------------------------------
五、触发时机（scene）
--------------------------------------------------------------------------------

用 scene 标识「在哪儿尝试弹」，便于配置与统计：

  scene           建议触发点                    默认是否启用
  --------------  ----------------------------  --------------
  app_launch      app.js onLaunch 后延迟 800ms   关（易打扰）
  home_show       首页 tab onShow               开
  complete_show   生成完成页 onShow             开
  player_show     播放页 onShow                 开
  after_generate  生成成功写入 myWorks 后        开（转化好）
  community_show  盒友圈 onShow                 关
  mine_show       我的 onShow                   关

触发流程（每处相同）：

  onShow() {
    if (isBlockingRoute()) return          // 生成中/登录强制页等
    promoScheduler.tryShow({ scene: 'home_show' })
  }

  // tryShow 内部异步，不阻塞首屏渲染；建议 request 完成后再弹

禁止弹窗的黑名单页面（硬编码）：
  - pages/create/generating
  - pages/create/tracks（若正在录音）
  - package-community/pages/post/create
  - 任何 showLoading / 分享 canvas 绘制中

六、频控规则（核心）
--------------------------------------------------------------------------------

6.1 全站统一的本地存储（替代现有三个 key）

  key 说明：
    mb_promo_dismiss_date          值：YYYY-MM-DD（上海时区）
                                   含义：用户选了「今天不再显示」任一弹窗

    mb_promo_session_closed_ids    值：JSON 数组 promoId
                                   含义：本次冷启动内「仅本次关闭」的 id 列表

    mb_promo_last_show_at          值：时间戳 ms
                                   含义：上一次任意弹窗展示时间（用于最小间隔）

    mb_promo_daily_count_YYYYMMDD  值：数字
                                   含义：当天已展示次数（跨 scene 累计）

  判定能否展示（伪代码）：

    function canShow(promo, scene) {
      if (!MIANJIA_ENTRY_ENABLED && promo.category === 'mianjia') return false
      if (getDismissDate() === today()) return false
      if (sessionClosed.includes(promo.id)) return false
      if (dailyCount >= promo.maxPerDay) return false
      if (now - lastShowAt < promo.minIntervalMs) return false
      if (!promo.scenes.includes(scene)) return false
      if (promo.startAt / promo.endAt 不在有效期) return false
      return true
    }

  建议默认阈值（可配置覆盖）：
    maxPerDay: 1              // 全站每天最多 1 次强弹窗
    minIntervalMs: 4 * 3600e3 // 两次弹窗至少间隔 4 小时
    priority: 数字越大越优先   // 多活动同时命中只弹一个

6.2 与现有横幅的关系

  - 横幅（mianjia-entry）：轻量常驻，可继续保留；关闭走统一 mb_promo_dismiss_date。
  - 强弹窗（center_image）：走 scheduler，与横幅互斥或降权：
      若当天已弹过强弹窗，当天不再弹横幅（可选，产品定）。

6.3 「仅本次关闭」vs「今天不再显示」

  与现网交互一致，但存储改为全站：
    仅本次关闭 → sessionClosed  push promoId
    今天不再显示 → setDismissDate(today)，并 hide 所有 scene 的弹窗/横幅

七、远程配置与接口（推荐）
--------------------------------------------------------------------------------

7.1 接口草案

  GET /api/promo/active
  Query: scene=home_show, platform=miniapp
  Response:
    {
      "code": 0,
      "data": {
        "list": [
          {
            "id": "mianjia_2025_q2",
            "type": "center_image",
            "priority": 100,
            "scenes": ["home_show", "complete_show", "player_show"],
            "title": "眠家深睡 · 好物推荐",
            "subtitle": "搭配助眠音乐，探索精选",
            "imageUrl": "https://.../banner.png",
            "buttonText": "去看看",
            "linkType": "miniapp",
            "linkPath": "/package-mall/pages/mianjia/index",
            "maxPerDay": 1,
            "minIntervalHours": 4,
            "startAt": "2025-01-01T00:00:00+08:00",
            "endAt": "2025-12-31T23:59:59+08:00",
            "enabled": true
          }
        ]
      }
    }

  POST /api/promo/event（可选，用于统计）
  Body: { promoId, scene, action: "show" | "click" | "close_once" | "close_today" }

7.2 无后端时的兜底

  utils/promo-fallback.js 内写 1～2 条本地配置，与 mianjia-config 开关联动；
  接口失败 silentFail，不弹窗，不影响主流程。

7.3 后台运营（后期）

  简单 SQLite 表 promo_campaigns，或 JSON 热更新；
  宝塔改配置 + pm2 restart，不必每次发小程序版（素材图仍要 HTTPS 合法域名）。

九、组件接口示例
--------------------------------------------------------------------------------

  // 页面 wxml
  <promo-popup
    visible="{{promoVisible}}"
    promo="{{promoPayload}}"
    bind:close="onPromoClose"
    bind:confirm="onPromoConfirm"
  />

  // 页面 js
  const promoScheduler = require('../../utils/promo-scheduler')

  onShow() {
    promoScheduler.tryShow({
      scene: 'home_show',
      onShow: (payload) => this.setData({ promoVisible: true, promoPayload: payload })
    })
  }

  onPromoClose(e) {
    promoScheduler.handleClose(e.detail)  // { promoId, mode: 'session'|'today' }
    this.setData({ promoVisible: false })
  }

  onPromoConfirm(e) {
    promoScheduler.handleClick(e.detail)
    promoScheduler.navigate(e.detail.linkPath)
    this.setData({ promoVisible: false })
  }

十、实施步骤（建议分三期）
--------------------------------------------------------------------------------

  第一期（1～2 天，可不发后端）
    · 新建 promo-scheduler + promo-popup（center_image 一种）
    · 全站统一 dismiss / 日次数 / 最小间隔
    · 首页 onShow 接一条本地兜底活动（眠家商城）
    · 迁移三个旧 dismiss key

  第二期
    · 完成页、播放页接入同一 scheduler
    · 横幅关闭与弹窗共用频控
    · GET /api/promo/active 对接后端

  第三期
    · 上报 show/click/close
    · 后台配置多条活动、优先级、AB
    · bottom_card 模板、after_generate 场景

十一、测试清单
--------------------------------------------------------------------------------

  [ ] 首页选「今天不再显示」→ 完成页/播放页当天不再弹
  [ ] 仅本次关闭 → 切 tab 再回来可不弹；杀进程重进可再弹（未选今天）
  [ ] 同一天手动进三次首页，最多弹 maxPerDay 次
  [ ] 间隔不足 minInterval 不弹
  [ ] 生成中页 onShow 不弹
  [ ] 接口失败不白屏、不 Toast 报错
  [ ] 夜览主题下弹窗对比度正常
  [ ] 点击主按钮正确跳转眠家分包

--------------------------------------------------------------------------------
十二、与「酷狗 / 网易云」对照（便于理解）
--------------------------------------------------------------------------------

  能力              大厂常见做法                 本方案对应
  ----------------  ---------------------------  ---------------------------
  弹不弹            服务端配置 + 人群            /api/promo/active + enabled
  弹几次            日上限、会话上限             maxPerDay + sessionClosed
  何时弹            启动、首页、播放、行为事件   scene 枚举
  弹什么            优先级队列                   priority 取最高一条
  关掉之后          本地 + 服务端埋点            dismiss_date + 可选 event 上报
  不打断听歌        与播放器解耦                 本方案明确不涉及续播

--------------------------------------------------------------------------------
十三、产品建议（眠音盒场景）
--------------------------------------------------------------------------------

  1. 强弹窗建议每天最多 1 次，避免助眠用户反感。
  2. 晚间 21:00～07:00 可提高眠家/助眠商品权重，白天可降低或只显示横幅。
  3. 新用户首次完成生成后（after_generate）转化率通常最好，可单独配一条高优先级活动。
  4. 弹窗主视觉与小程序「雾白 + 雾蓝」一致，勿用刺眼高饱和红底促销风。
