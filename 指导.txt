《眠音盒视觉规划方案》
——眠家数智睡眠生态中的AI音乐礼物视觉系统

一、视觉定位总纲
1.1 眠音盒不是普通音乐App
“眠音盒”不能做成普通的播放器界面，也不能做成单纯的AI工具界面。它应该是眠家体系里的一个 情绪化、礼物化、可传播的数字睡眠入口。
它的视觉核心应该是：
像打开一只深夜里的音乐盒，里面有AI为你生成的一首晚安曲，也有一份可以送给别人的温柔祝福。
所以，眠音盒的视觉不能只强调“音乐”，还要同时表达四层气质：
1.睡眠感：夜晚、月光、星辰、安静、放松。 
2.AI感：生成、声波、数据、智能、个性化。 
3.礼物感：贺卡、包装、丝带、打开、惊喜。 
4.眠家感：关爱、陪伴、深睡、为努力的人充电。 
你提供的文件里已经把眠音盒的核心意象定义为“八音盒/音乐盒”，并且强调“旋转、旋律、时光、陪伴”，这个方向非常准确，建议继续强化为整个产品的视觉锤。
二、眠音盒在眠家视觉体系中的位置
2.1 眠家整体视觉气质
从我们之前对眠家、深睡房、SSF视觉策略的讨论来看，眠家整体视觉应该形成一种：
深睡科技感 + 东方温柔感 + 家庭关爱感 + 高级疗愈感
它不是医院式健康品牌，也不是普通家居品牌，更不是纯互联网工具品牌。
眠家的视觉关键词可以归纳为：
关键词	表达方式
数智	AI、数据、光线、科技界面
深睡	夜色、月光、柔和渐变、安静空间
关爱	人物情绪、礼物、陪伴、亲情关系
东方	留白、柔和曲线、温润色彩、含蓄表达
系统	模块化界面、五维方案、产品矩阵

2.2 眠音盒的独立视觉角色
在整个眠家体系里，眠音盒应该更轻、更柔、更有分享感。
如果说：
眠家深睡房 是“专业系统解决方案”；
SSF深睡系统 是“科技能力与空间场景”；
眠音盒 就是“用户第一次接触眠家的温柔入口”。
因此，眠音盒的视觉可以比深睡房更梦幻一点，比产品包装更年轻一点，比医疗健康视觉更有情绪一点。
它的视觉定位建议为：
深夜里的一只AI音乐礼盒。
三、核心视觉概念
3.1 主视觉概念：夜色音乐盒
眠音盒的核心视觉锤应该是：
一只在深蓝夜色中缓缓打开的音乐盒，盒中升起星光、音符、声波与月光。
这个视觉可以贯穿：
启动页；
Logo动效；
首页核心按钮；
AI生成过程；
音乐贺卡打开动画；
分享海报；
节日活动页；
会员权益页。
3.2 视觉关键词
建议确定以下八个视觉关键词：
关键词	视觉表达
开盒	盒盖打开、光线溢出、音符升起
入梦	星光、月亮、云雾、柔焦渐变
AI生成	声波、粒子、光环、数据流
音乐	音符、旋转舞台、唱片纹理、节奏波形
礼物	贺卡、丝带、封套、礼盒包装
陪伴	温暖文字、人物剪影、睡前场景
深睡	深蓝、低亮度、柔和对比
眠家	科技关爱、家庭温度、系统解决方案入口

四、Logo与品牌符号规划
4.1 Logo设计方向
Logo路线：
音乐盒图形Logo为主，AI声波元素作为辅助。
原因是眠音盒最大的差异化不是“AI音乐”，而是“AI音乐礼物”。音乐盒的情绪记忆比纯声波更强，也更适合“贺卡分享”场景。
4.2 Logo动态化
眠音盒Logo一定要有动态版本。
启动页动效建议：
1.深蓝背景渐亮； 
2.音乐盒轮廓出现； 
3.盒盖轻轻打开； 
4.盒内升起金色微光； 
5.音符和星光粒子飘出； 
6.品牌名“眠音盒”淡入； 
7.Slogan出现：
8.打开眠音盒，听见好梦。
9.动效时间控制在 2.5-3秒。

五、色彩系统规划
你提供的文件中已经定义了梦夜蓝、星尘金、月光白、薰衣草紫、薄荷绿、珊瑚粉、深空灰等颜色体系。
这个色彩方向是成立的，但我建议做一次层级优化，让它更适合产品界面和长期运营。

5.1 主色系统
主色一：眠夜蓝
建议用于主背景、启动页、音乐播放页、品牌识别。
参考色值：
#202B48 / #2D3A5C
气质：深睡、安静、夜晚、专业。

主色二：星尘金
用于按钮、高级权益、音符高光、音乐盒金属件。
参考色值：
#D4AF37 / #E6C76A
气质：礼物感、珍贵感、温度、会员感。

主色三：月光白
用于文字、卡片、留白、柔和背景。
参考色值：
#F5F5F0 / #FFFDF5
气质：干净、温柔、可阅读。

5.2 辅助色系统
薰衣草紫
适合女性向、情侣、疗愈、晚安贺卡。
参考色值：
#9B8FBF

薄荷绿
适合自然音、森林、雨声、呼吸放松。
参考色值：
#7FB3A3

珊瑚粉
适合母亲节、亲子、朋友祝福、温暖关系。
参考色值：
#E8A598
星雾蓝
建议新增一个辅助色，用于更年轻、更梦幻的页面。
参考色值：
#6F8FCF
适合音乐生成进度、声波动画、科技光效。
5.3 色彩使用比例
建议比例为：
色彩	使用比例	用途
眠夜蓝	45%	主背景、品牌底色
月光白	25%	卡片、文字、留白
星尘金	10%	按钮、重点、高级感
薰衣草紫	8%	情绪主题
薄荷绿	6%	自然主题
珊瑚粉	4%	温情主题
星雾蓝	2%	AI光效、科技点缀

5.4 避免的问题
不要整套界面一直纯黑。
眠音盒应该是“深夜温柔”，不是“压抑黑暗”。
不要过度使用金色。
金色只用于关键点，否则容易显得廉价或像游戏充值界面。
不要过度少女化。
它可以温柔，但不能变成单纯粉紫色恋爱App。
不要过度游戏化。
文件中有盲盒、称号、等级系统，这些可以保留，但视觉上要克制，不能做成抽卡手游。

六、字体系统规划
6.1 中文字体
建议使用三类字体：
层级	字体建议	用途
品牌标题	思源宋体 / 方正清刻本悦宋 / 阿里妈妈东方大楷适度使用	Logo、副标题、贺卡标题
正文信息	思源黑体 / HarmonyOS Sans / 苹方	App正文、按钮、说明
情绪文案	手写体或轻书法字体	贺卡祝福、签名、节日文案

6.2 英文字体
层级	字体建议	用途
品牌英文	Playfair Display	高级、艺术感
界面英文	SF Pro / Inter	简洁现代
数字数据	DIN / Roboto Mono	时间、播放进度、睡眠评分

6.3 字体气质原则
眠音盒的字体不要太硬，也不要太幼稚。
建议：
标题：有一点诗意；
正文：清晰克制；
贺卡：温柔手写感；
数据：现代科技感。

七、核心图形资产规划
7.1 音乐盒
音乐盒是第一视觉符号。
建议设计四个版本：
版本	视觉特点	使用场景
标准版	深蓝盒体、金色边框、月光内核	Logo、首页、启动页
水晶版	半透明盒体、内部星光流动	会员、高级音乐、限定活动
节日版	可替换主题装饰	春节、母亲节、情人节
线性版	简化线条图标	Tab、按钮、加载状态

7.2 音符系统
音符不能只是普通符号，应该变成眠音盒独有的“梦音符”。
设计建议：
音符头部像小月亮；
音符尾部像声波；
音符周围带微小星光；
播放时音符轻微跳动；
生成完成时从盒中飘出。

7.3 声波系统
声波代表AI生成能力。
建议分三类：
声波类型	用途
环形声波	生成中、AI分析中
横向波形	播放器、音乐详情
粒子声波	高级视觉、分享视频
声波颜色建议使用星雾蓝、月光白、星尘金，不要用强烈霓虹色。

7.4 星月系统
星月代表睡眠场景。
可以设计：
月牙；
星尘；
云雾；
柔光；
夜空渐变；
窗边月光。
适合用于：
首页背景；
贺卡封面；
节日海报；
睡眠挑战页。

7.5 礼物系统
礼物感是眠音盒传播的关键。
建议设计：
礼盒；
丝带；
信封；
贺卡；
封蜡；
打开动画；
祝福标签。
每一张音乐贺卡都应该像“收到了一份礼物”，而不是“点开了一个链接”。

八、App / 小程序界面视觉规划
8.1 启动页
画面结构
背景：深蓝夜空渐变
中心：音乐盒Logo
动效：盒盖打开，星光与音符飘出
文字：眠音盒
Slogan：打开眠音盒，听见好梦
气质
安静、期待、有仪式感。

8.2 首页：我的眠音盒
首页不要做成信息流首页，而要做成“开盒入口”。
推荐结构
顶部：
今晚，想把哪种心情放进音乐盒？
中间：
一个可交互的3D音乐盒。
主按钮：
今晚开盒
辅助入口：
我的音乐；
我收到的贺卡；
送TA晚安；
盒友圈精选。
底部Tab：
音乐盒 / 贺卡 / 盒友圈 / 睡眠 / 我的

8.3 AI生成页：开盒生成
视觉流程
第一步：选择对象
自己 / 妈妈 / 爱人 / 孩子 / 朋友
第二步：选择状态
睡不着 / 压力大 / 想放松 / 想被陪伴 / 想安静
第三步：选择声音
雨声 / 钢琴 / 白噪音 / 古琴 / 星空氛围
第四步：选择时长
5分钟 / 15分钟 / 30分钟 / 睡前循环
第五步：点击生成
按钮文案建议：
开始谱梦
或者：
打开音乐盒

8.4 生成中页面
生成中不能只是进度条。
建议使用：
音乐盒缓慢旋转；
声波环绕盒体；
盒内有光逐渐增强；
音符偶尔飘出；
文案逐句变化。
生成中文案示例：
正在读取今晚的心情
正在为你调配一段柔和旋律
正在加入一点月光和雨声
你的晚安曲快完成了

8.5 生成完成页
页面重点
音乐名称；
音乐播放按钮；
贺卡封面；
祝福语；
分享按钮。
核心按钮：
送给TA
次级按钮：
自己听
换一张封面
修改祝福语
保存到我的音乐盒

8.6 音乐播放页
视觉建议
背景：缓慢流动的夜空
中心：旋转音乐盒或月亮唱片
下方：波形播放器
底部：收藏、循环、定时关闭、分享
播放页要尽量安静，不要有太多按钮干扰睡眠。
推荐增加：
睡眠模式
进入睡眠模式后：
屏幕亮度降低；
按钮减少；
只保留暂停、定时关闭；
背景变暗；
减少动效。

8.7 贺卡页
贺卡页是眠音盒的传播核心。
贺卡结构
封面：主题视觉
中间：祝福语
底部：播放按钮
右下角：眠音盒水印
打开动效：礼盒/信封/音乐盒打开
贺卡类型
类型	视觉方向
给妈妈	珊瑚粉 + 月光白 + 柔和花影
给爱人	薰衣草紫 + 星光 + 双人剪影
给孩子	星月蓝 + 小云朵 + 童话感
给朋友	薄荷绿 + 轻松插画
给自己	深蓝 + 月亮 + 独处感
节日卡	根据节日替换元素

8.8 盒友圈页面
盒友圈不要做成普通社区，可以做成“夜晚广场”。
页面视觉
背景更浅一些，避免长时间阅读压抑。
卡片使用月光白或雾蓝白。
内容卡片像一张张小音乐卡。
内容卡片结构
用户头像；
音乐名称；
一句睡眠经验；
播放按钮；
点赞 / 收藏 / 评论；
标签：#雨夜听窗 #考前放松 #给TA的晚安曲

8.9 睡眠页
这个页面用于连接眠家生态。
内容包括：
AI睡商检测入口；
睡眠打卡；
睡眠音乐使用记录；
睡眠建议；
眠家产品推荐；
深睡房体验入口。
视觉上要比音乐页更专业一点，体现“眠家系统能力”。

九、贺卡视觉体系
9.1 贺卡是眠音盒最重要的传播资产
眠音盒能不能传播，很大程度取决于贺卡是否足够好看、足够有情绪、足够愿意被分享。
贺卡不能像普通电子明信片，而要像：
一张会唱歌的晚安礼物。

9.2 贺卡基础模板
建议第一阶段设计6类模板：
1. 晚安星光卡
适合：通用晚安、朋友、自己。
视觉：深蓝夜空、星光、音乐盒。

2. 妈妈摇篮曲卡
适合：母亲节、亲情。
视觉：珊瑚粉、月光白、柔和花瓣、母子剪影。

3. 心动晚安卡
适合：情侣、七夕、情人节。
视觉：薰衣草紫、双月、星河、细金线。

4. 宝贝入梦卡
适合：亲子、儿童睡前。
视觉：浅蓝、云朵、小星星、童话音乐盒。

5. 雨夜听窗卡
适合：白噪音、雨声爱好者。
视觉：窗户、雨滴、微光、室内温暖灯。

6. 给自己的晚安卡
适合：自我疗愈、压力人群。
视觉：一个人、月光、安静房间、柔和留白。

9.3 贺卡文案视觉规则
贺卡文字不要太多。
建议结构：
标题：8字以内
正文：20-40字
署名：用户昵称
按钮：听这首晚安曲
例如：
标题：
妈妈，今晚好好睡
正文：
你把我的夜晚哄成星辰，这一次，换我把深睡还给你。
按钮：
打开晚安曲

十一、动效系统规划
11.1 核心动效：开盒
这是眠音盒的主品牌动作。
标准动效：
盒盖缓缓打开；
内部光线扩散；
音符上升；
声波扩散；
星尘粒子浮动。
时长：800ms-1200ms。
节奏：慢启动，柔和结束。
感觉：轻、柔、惊喜，不要像游戏爆奖。

11.2 生成动效
音乐盒旋转；
声波环绕；
AI粒子流入盒内；
进度光环慢慢闭合。

11.3 播放动效
音乐盒低速旋转；
音符轻微跳动；
背景星光缓慢移动；
波形轻柔起伏。

11.4 收到贺卡动效
礼盒从屏幕中央浮现；
丝带轻轻松开；
盒盖打开；
音乐自动淡入；
祝福语逐字出现。

11.5 睡眠模式动效
所有动效降速；
背景变暗；
减少粒子数量；
屏幕渐隐；
只保留音乐波形和定时关闭。

十二、插画与人物风格
12.1 人物风格
眠音盒可以使用人物插画，但要克制。
人物不宜太卡通，也不宜太写实。
建议风格：
半写实柔和插画；
低饱和色；
温柔光影；
人物动作安静；
场景有生活感。

12.2 典型人物场景
可以设计以下场景：
妈妈坐在床边听晚安曲；
年轻情侣异地互发音乐贺卡；
学生考前戴耳机听白噪音；
白领深夜关灯听助眠音乐；
孩子抱着玩偶入睡；
用户一个人在窗边听雨声。

12.3 与眠家IP形象结合
如果眠家已有IP人物，可以让它作为“眠音盒里的小助手”出现。
角色设定可以是：

视觉上可以用小卡片浮层，不要弹窗强推。
