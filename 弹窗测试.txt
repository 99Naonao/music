二、为什么感觉单调（问题诊断）
--------------------------------------------------------------------------------

  1. 看板层
     · 只有 4 类核心指标（DAU / 绑定 / 音乐完成 / 贺卡），缺少漏斗与留存
     · 趋势图是 CSS 柱状条，无折线/堆叠/同比环比
     · 无「今日实时 vs 昨日同期」、无异常高亮（涨跌 >20% 标红）
     · 无单渠道详情页（从排行点进去看该渠道 30 天曲线）

  2. 运营层
     · 反馈只能看，不能标记「已处理 / 已回复 / 忽略」
     · 社区只能删帖，不能删评论、禁言用户、置顶优质帖
     · 弹窗编辑是裸 JSON，运营不敢改；无预览、无按场景模拟
     · 渠道 Branding 无「小程序预览二维码」一键生成

  3. 内容层
     · 官方曲库、贺卡模板、商城商品仍在代码/脚本里，后台不可配
     · 无 Banner / 首页推荐位 / 任务活动配置
     · promo 曝光点击数据未回收到看板（POST /api/promo/event 仅写日志）

  4. 治理层
     · admin_audit_logs 已有数据，但 UI 无「谁在何时改了什么」
     · 无管理员账号管理（改密、新建 operator、禁用账号）
     · 无合同到期提醒、渠道 health 红绿灯

  5. 体验层
     · 侧栏 6 项平铺，无分组（数据 / 运营 / 配置 / 系统）
     · 无首页「待办」：未处理反馈数、待审帖子、即将到期合同
     · 无深色模式、无移动端适配（运营外出只看数）

  【P0-1】看板升级 · 运营驾驶舱首页 ⭐⭐⭐  🔧中  📦 ECharts + 现有 stats API
    · 折线图替代纯柱状（DAU / 音乐 / 贺卡 多指标切换）
    · 同比：较昨日 / 较上周同日 百分比小标签
    · 渠道详情：点击排行 → /dashboard/channel/:id 专页
    · 迷你 KPI：音乐生成中 vs 已完成、今日新增用户数
    · 可选：接入 POST /api/promo/event 聚合 → 「弹窗曝光 / 点击」卡片

  【P0-2】工作台 · 待办与快捷入口 ⭐⭐⭐  🔧低  📦 聚合现有 API
    · 登录后首页卡片：
        - 未读反馈 N 条（需加 status 字段，见 P0-3）
        - 近 7 日零 DAU 渠道列表（异常提醒）
        - 合同 30 天内到期渠道（channels.contract_end）
        - 快捷：新建渠道 / 导出月报 / 查看昨日 DAU
    · 侧栏分组：概览 | 数据 | 运营 | 配置 | 系统

  【P0-3】反馈工作流 ⭐⭐⭐  🔧低  📦 user_feedback 加 status / admin_note
    · 状态：pending → processing → resolved → ignored
    · 列表筛选 + 运营备注 + 处理人 + 处理时间
    · 看板增加「待处理反馈」计数
    API：PATCH /api/admin/feedback/:id

  【P0-4】弹窗可视化编辑 ⭐⭐⭐  🔧中  📦 替代 JSON  textarea
    · 表单字段：标题、副标题、按钮文案、场景多选、规则、优先级
    · 「预览 JSON」折叠区给高级用户
    · 按 scene 模拟：选 home_show + channel → 展示将命中哪条活动
    · 活动效果：近 7 日 exposure / click / dismiss（需聚合 promo event）

  【P0-5】操作审计页 ⭐⭐  🔧低  📦 admin_audit_logs 已有
    · /audit 列表：时间、操作人、动作、目标、IP
    · 筛选：渠道变更 / branding / 登录 / 弹窗
    API：GET /api/admin/audit-logs?from=&to=&action=

  ┌─────────────────────────────────────────────────────────────────────────┐
  │ P1 · 中期增强（2～4 周，形成完整运营闭环）                               │
  └─────────────────────────────────────────────────────────────────────────┘

  【P1-1】社区审核增强 ⭐⭐  🔧中
    · 帖子详情：评论列表、点赞数、关联音乐
    · 删评论（复用现有 community-service 逻辑）
    · 用户维度：某 openid 近 30 天发帖数（简易风控）
    · 可选：敏感词命中高亮（接 content-security 结果缓存）

  【P1-2】渠道运营包 ⭐⭐⭐  🔧中
    · 渠道详情页整合：Branding + 近 30 天曲线 + 合同信息 + 审计记录
    · 一键生成渠道体验链接 / 小程序码参数说明
    · 渠道复制：从 channel_1 复制 branding 到新渠道
    · 批量启停（活动结束批量 disabled）

  【P1-3】漏斗与留存看板 ⭐⭐⭐  🔧高  📦 biz_events 或业务表统计
    · 漏斗：启动 → 登录 → 生成音乐 → 完成 → 贺卡 → 分享
    · 按渠道对比转化率（需统一埋点 event_type）
    · 7 日留存：D0 启动用户在 D1/D7 是否回访
    · 依赖：小程序埋点补全 + 日聚合脚本扩展

  【P1-4】内容配置台（曲库 / 贺卡 / Banner） ⭐⭐  🔧高
    · 官方曲库：上下架、排序、封面（现 partly 在 DB + 脚本）
    · 贺卡模板：触发 sync-card-templates + Admin 列表启停
    · 首页 Banner / 任务入口：新表 home_banners，小程序 GET 公开 API
    · 减少改代码发版频率

  【P1-5】导出增强 ⭐⭐  🔧中
    · XLSX（exceljs）多 Sheet：汇总 + 分渠道明细
    · 定时月报：每月 1 号邮件/企业微信推送 CSV 链接（可选）
    · 导出任务持久化（现内存 Job，重启丢失 → 改落盘 + 24h 清理）

  【P1-6】系统管理 ⭐⭐  🔧中
    · /settings/admins：super 管理后台账号（CRUD、重置密码）
    · /settings/account：当前用户改密
    · /settings/health：DB 大小、最近聚合时间、Node 版本、磁盘 uploads

  ┌─────────────────────────────────────────────────────────────────────────┐
  │ P2 · 规模化 / 商务向（Phase 3，4～8 周）                                  │
  └─────────────────────────────────────────────────────────────────────────┘

  【P2-1】M5 Partner 门户 ⭐⭐⭐  🔧中  📦 指导.txt §4.5
    · partner 登录后独立首页：仅本渠道 KPI + 导出 + 素材下载
    · 白标 PDF 月报（带渠道 Logo）
    · 可选：partner 提交 branding 变更 → 我方审批流

  【P2-2】结算与合同 ⭐⭐⭐  🔧高
    · channels 表补 contract_start/end、KPI 目标 JSON
    · 自动生成「月度 KPI 达成报告」对比合同指标
    · 到期邮件 / 企微提醒

  【P2-3】告警中心 ⭐⭐  🔧中
    · 规则：DAU 连续 3 天跌 30%、封面上传失败率 >5%、API 5xx 突增
    · 通知：企业微信 webhook / 邮件
    · 后台「告警历史」页

  【P2-4】BI 外挂（可选） ⭐  🔧低
    · Metabase / Superset 只读连接 SQLite 或 PG 副本
    · Admin 内嵌 iframe 或链接跳转
    · 适合复杂 ad-hoc 分析，不替代 M1 配置台

  【P2-5】A/B 与实验 ⭐  🔧高
    · 同场景多活动按流量百分比分配
    · 实验结论回流看板
